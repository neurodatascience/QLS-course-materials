# Exercise 2: Encode a simple visualization

## Task
1. Write a python script to create the figure that you planned in exercise 1.
2. Compare your code with the partner who planned the figure with you.

## Optional: Use AI as a coding assistant

You can use AI to help write or debug your code — but with one rule: **you must be able to explain every line before you move on.**

Try this workflow:
1. Ask AI to generate a first draft of your figure code
2. Read through it line by line — add a comment above each line explaining what it does in your own words
3. Compare with your partner's AI-generated code: did the AI make different choices (e.g. different plot type, color scheme, axis labels)? Which do you prefer and why?

This way you learn the code rather than just copying it.
