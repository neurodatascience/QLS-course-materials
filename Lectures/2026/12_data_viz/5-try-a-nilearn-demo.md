# Exercise 5: Try a Nilearn visualization demo

## Goal
To learn a bit about plotting brains.

## Task
- Go to [the Nilearn webpage on plotting](https://nilearn.github.io/stable/plotting/index.html#plotting)
- Choose an example
- Scroll to the end of the page
- Click the box to download an .ipynb file containing the demo
- Move the demo into this folder
- Open the jupyter notebook from inside your python environment

## Optional: Use AI to understand and extend the demo

Pick a demo that has code you don't fully understand, run it, then use AI to dig into it:

1. **Understand it:** Paste the notebook code into an AI and ask:
   > "Explain this Nilearn plotting code step by step. What does each function do, and what are the key parameters I might want to change?"

2. **Extend it:** Ask the AI a small "what if" question, for example:
   > "What would I change to plot a different brain atlas instead of the one used here?"
   
   Then actually make that change in the notebook and run it.

The goal is to leave this exercise knowing how to navigate an unfamiliar library with AI help — a skill you'll use constantly.
